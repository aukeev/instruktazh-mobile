Список персонала

Загрузите выгрузку из отдела кадров в Excel или CSV. Нужны столбцы: ФИО (или Фамилия, Имя, Отчество), ИИН, табельный номер, должность, подразделение. Подразделения вида «Объект / Участок» можно выбирать и целиком, и по участкам. Год рождения можно не указывать, он определяется по ИИН. Файл обрабатывается только в этом браузере.

Общий сервер журнала

Записи с телефонов инструктирующих приходят сюда автоматически. Журнал сам забирает новые записи с сервера и отправляет туда записи, созданные на этом компьютере.

Список персонала на сервере нужен телефонам инструктирующих: они загружают его сами. Отправлять список может инженер ОТОС.

Архив

Все данные лежат в памяти этого браузера. Регулярно сохраняйте архив в файл: в нем записи, сами подписи (CMS) и список персонала.

Повторный инструктаж

По п. 62 Правил № 1019 повторный инструктаж проводится не реже одного раза в полугодие. Заменяет ли его внеплановый, Правила не говорят, поэтому по умолчанию внеплановый не учитывается. Считаются только инструктажи, подписанные работником.

Режим

Подпись идет через сервис SIGEX (sigex.kz): страница передает текст записи, работник сканирует QR в eGov Mobile, проверяет текст и подписывает своей ЭЦП. Подписанный файл (CMS) сохраняется в журнале и может быть проверен на sigex.kz.
