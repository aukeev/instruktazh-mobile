# Инструктаж КарНУ — мобильное приложение инструктирующего

Устанавливаемое веб-приложение (PWA) для проведения инструктажей по БиОТ с телефона.
Записи создаются в том же формате, что и в «Журнал_инструктажей_ЭЦП.html», и передаются в журнал файлом .json.

## Как пользоваться
1. Откройте ссылку на приложение в Chrome (Android) или Safari (iPhone) и добавьте на главный экран.
2. ⚙ Настройки: укажите свои ФИО и должность, загрузите штатку (CSV: ФИО; ИИН; Табельный номер; Должность; Подразделение) или архив .json журнала. Задайте PIN.
3. «Новый инструктаж»: подразделение, вид, причина (для внепланового и целевого), инструкции, дата.
4. «Кто присутствует»: отметьте работников, при необходимости добавьте человека вручную.
5. Каждый работник сканирует QR своим eGov Mobile («eGov QR») и подписывает. ФИО и ИИН сверяются с сертификатом; если ИИН не был известен, он берётся из сертификата.
6. Инструктирующий подписывает последним кнопкой «Открыть eGov Mobile» на этом же телефоне. Запись закрыта.
7. «Выгрузить в журнал»: файл .json импортируется в журнал на компьютере. После импорта выгруженные записи можно удалить с телефона (Настройки → Очистка).

## Правила подписи
- Сверка (как в журнале v1.1): `ok` — ИИН совпал; `name` — ИИН не был известен, совпали фамилия и имя (ИИН берётся из сертификата); `warn` — требует ручной сверки; `bad` — ИИН в ЭЦП не совпал (не засчитывается, запись не закрыть). ИИН проверяется по контрольной цифре.
- Повторная подпись не затирает прежнюю: она сохраняется в `worker.sigHistory`.
- Демо-подписи (`sig.demo=true`) закрывают запись только в демо-режиме, запись получает `demo: true`.

## Данные
Все данные хранятся только на телефоне (localStorage). На хостинг попадают только файлы программы.
Подпись идёт через сервис SIGEX (sigex.kz), нужен интернет. Остальное работает без сети.
PIN защищает от случайного просмотра, но не шифрует данные.

## Файлы
`index.html`, `app.js` — приложение; `sigex.js` — клиент SIGEX QR (MIT, © SIGEX); `sw.js` — офлайн-кэш; `manifest.webmanifest`, `icon*` — установка.

Для камеры и установки нужен HTTPS (GitHub Pages подходит).
